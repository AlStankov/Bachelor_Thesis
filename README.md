# Bachelor_Thesis
Contains all Jupyter Notebooks and relevant files for my Bachelor Thesis

## Author and University
This is Alexander Stankov's Bachelor Thesis at the IU International University of Applied Sciences

## Topic
Beyond Accuracy: A Comparative Study of Interpretable and Black-Box Models for Credit Default Prediction

## Supervisor
Dr. Tobias Broweleit

## Installation
Please, make sure to run the notebook eda.ipynb so that all requirements are installed.

## Jupyter Notebooks Naming
eda_and_data_prep.ipynb contains EDA and data preparation, including the creation of all relevant train, validation and test datasets
Every model is trained in a separate notebook entitled {model name}.ipynb
Model comaprison is performed in 2 notebooks: 
- model_comparison_techn.ipynb contains technical aspects
- model_comarison_underst.ipynb contains interpretability assessment

## Data Dictionary
A data dictionary is to be found in the file data_dictionary.xlsx

## Additional files
When running the Jupyter notebooks, several additional files will be created including model files. They are not attached in this repository due to their size.
